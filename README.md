# Arduino Force Sensor Alarm System

An Arduino-based alarm system that detects pressure or touch using a force sensor and activates an alert when force is applied.

## Components

* Arduino Uno
* Force Sensitive Resistor (FSR)
* Buzzer
* LED
* Resistors
* Jumper Wires
* Breadboard

## How It Works

The force sensor detects changes caused by pressure or touch and sends an input signal to the Arduino. When the detected force reaches the defined threshold, the Arduino activates the buzzer and LED as an alert.

## Features

* Force and touch detection
* Audible alarm
* Visual LED indication
* Adjustable detection threshold
* Arduino-based control

## Technologies Used

* Arduino Uno
* C/C++
* Force Sensitive Resistor (FSR)
* Basic electronic components

## Project Purpose

This project demonstrates how a force sensor can be interfaced with Arduino to detect pressure or touch and trigger an alert system.
